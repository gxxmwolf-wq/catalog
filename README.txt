Скопируйте папки api и private в G:\Мой диск\RX.

1. Вставьте новый токен в private\telegram_config.php.
2. Отправьте боту слово «тест».
3. После синхронизации откройте https://rxde.online/api/get_chat_id.php
4. Запишите показанный номер как telegram_chat_id.
5. Сразу удалите api\get_chat_id.php.
6. Добавьте /private/telegram_config.php в существующий .gitignore.
